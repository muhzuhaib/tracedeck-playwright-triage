# Third-party components

Tracedeck bundles open-source components, each used under its own licence (Apache 2.0, MIT and other permissive
licences).

The complete notices, with every licence text in full, ship inside the plugin itself, in the plugin's
`tracedeck/viewer/` folder (LICENSE, NOTICE and ThirdPartyNotices.txt). Open the plugin jar with any zip tool to read
them. They are kept with the plugin so that every copy of Tracedeck carries its notices.
